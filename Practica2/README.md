# Practica 2 

## Objetivo
El objetivo de esta practica es familiarizarse con la programacion de funcion en haskell, utilizando funciones "simples" con tipos de datos explicitos,
tales como:
- Double
- Float
- Int
- Bool
- Tuplas
- String

Tambien nos familiarizamos con las funciones predefinidas como sqrt (raiz cuadrada), if then else.

Ademas nos aseguramos de comprobar el funcionamiento de cada funcion en el interprete GHCI.

## Tiempo Requerido

Aproximadamente 9 hr
